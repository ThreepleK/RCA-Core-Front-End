# 1. Micro Front-end를 지향하며 준비된 프로젝트 입니다.

Monorepo 방식과 런타임에 코드가 통합+공유를 위해 아래와 같은 기술이 적용 되었습니다.

|적용 기술|적용 이유|소개|
|----|----|----|
|Pnpm|Monorepo 지원 + 효율적인 패키지 관리|[링크](https://pnpm.io/ko/motivation)|
|Turborebo|Monorepo 확장 + 전체 앱 빠른 빌드 시스템(병렬)|[링크](https://turbo.build/docs)|
|Module federation|Front-end 앱 런타임 중 코드 통합 공유|[링크](https://module-federation.io/guide/start/index.html)|

<br/><br/>

# 2. Host을 기준으로 앱을 불러 옵니다.

  ```
  Project
    └ Host
      ├ App 1
      ├ App 2
      ├ App 3
      └ ...
  ```

각각의 __앱을 개발할 때는__ Style(CSS)과 이미지, 폰트 등 __리소스 관리에__ 주의가 필요합니다.

|대상|기술 가이드|관리 이유|
|----|----|----|
|Style(CSS)|CSS-in-JS, CSS Module, Tailwindcss|1개 Micro App이 전체 스타일을 오염 시킬 수 있습니다.|
|Resources|[리소스 관리 가이드](./4.%20resource%20guide.md)|각각의 App 리소스는 별개로 관리되어야 합니다.|
