```
  - pnpm
     └ Modorepo(TurboRepo)
        ├ Host
        │  └ Vite + MF(@module-federation/vite)
        │     └ React(TS)
        └ tt
           └ Vite + MF(@module-federation/vite)
              └ React(TS)
```

  ```
    > cd ./apps

    > pnpm i
  ```

# Module federation 적용을 위한 기본 설정 값 추가
  ```ts [/packages/env/env-common.ts]
    //* 원격 앱 연결 키 값
    remoteAccessKey: {
        ...
        tt: 'tt',
    },
    
    //* 원격 앱 개발/배포 주소
    remoteAppHost: {
        development: {
          ...
          tt: `${_DEV_HOST}:5001`,
        },
        production: {
          ...
          tt: `${_PROD_HOST_REMOTE}/tt`,
        },
    },

    //* 연결 시 사용 될 항목 (각 앱 경로 기준)
    exposeSync: {
        tt: {
            './main': './src/App.tsx'
        },
    }
  ```
  * host와 tt를 연결하기 위한 기본 설정 값

<br /><br />

# tt 앱 Vite Module federation 적용 (아래 코드 참고)
  ```ts [/apps/tt/vite.config.ts]
  import { federation } from '@module-federation/vite';
  import envs from '../../packages/env/env-common';

  export default defineConfig((({ mode }: any) => {
    const remote = (envs.remoteAppHost as any)[mode];
    const accKey = envs.remoteAccessKey.tt;
    const exposes = envs.exposeSync.tt;
    const filename = envs.mf_fileName;

    return {
      build: {
        target: 'chrome89',
      },
      base: `${remote.rca}`,
      plugins: [
        federation({
          name: accKey,
          filename,
          exposes,
          shared: {
            react: { singleton: true }
          }
        }),
        react(),
      ],
      server: {
        port: 5001
      },
    };
  }))
  ```
  - federation 옵션
    |옵션|설명|
    |----|----|
    |name|모듈 이름 (or 앱 이름)|
    |filename|원격 모듈 호출 이름 (remoteEntry.js 고정)|
    |exposes|원격 모듈 호출 경로|
    |shared|React라면 위 설정 값과 동일|

  <br />

  - server 옵션
    |옵션|설명|
    |----|----|
    |port|host가 될 서버에서 호출하기 위한 고정 값|
    
    /packages/env-common.ts에 적용한 development 포트와 맞춰야 함

<br /><br />

# Host에 App 설정 연결 (remotes 변수 선언 아래 추가)
  ```ts [/apps/host/vite.config.ts]
    remotes[accKey.tt] = {
      type: "module",
      name: accKey.tt,
      entry: `${remote.tt}/${filename}`,
      shareScope: 'default'
    };
  ```
  |옵션|설명|
  |----|----|
  |accKey|공용 환경 변수에서 사용되는 원격 연결 키 값|
  |remote|원격 주소 관련 (개발/운영)|
  * __key(name 아님)__ 값이 /apps/tt/vite.config.ts 에서 name으로 설정 한 값과 __동일__ 해야 함
  * __entry는__ /apps/tt/vite.config.ts에 설정한 포트와 filename 기준으로 __정확한 주소가 설정__ 되어야 함
