# 리소스는 $resourceUrl 로 관리 합니다.
  유기적으로 통합되기 위해서는 번들링 툴(Vite, Webpack 등)에서<br />
  지원하는 define을 사용하여 <span style="color:#fd3">__전역 상수 값__</span>으로 __$resourceUrl를__ 적용해주세요. <br />
  여기서는 Vite를 기준으로 설명합니다.

<br />

# 사용해야 하는 이유?

  ```
  Project
    └ Host     http://localhost:5000
      ├ App 1  http://localhost:5001
      ├ App 2  http://localhost:5002
      └ ...
  ```

  각각의 앱은 실제 배포 시에 <span style="color:#f39">__다른 도메인을__</span> 사용하게 됩니다.<br />
  하지만 Host에서는 App 1, 2의 <span style="color:#fd3">__공유된 스크립트(JS)__</span>를 사용하는데,<br />
  Host 도메인을 기준으로 리소스를 불러오기 때문에 <span style="color:#39f">__없는 리소스를 요청__</span>하게 됩니다.
  
  ||통합 접속|개별 접속|소스 경로|개발/배포 url|
  |----|----|----|----|----|
  |Host|✔️|✔️|/apps/host/public/*|http://localhost:5000|
  |App 1|❌|✔️|/apps/app1/public/logo.png|http://localhost:5001|
  |App 2|❌|✔️|/apps/app2/public/logo.png|http://localhost:5002|

  그래서 각각 앱의 도메인에 <span style="color:#f39">__직접 접속할__</span> 경우 문제가 없지만,
  <span style="color:#39f">__통합 되어 배포__</span> 되었을 때는 문제가 됩니다.

<br />

# 관리하는 방법
  1. 리소스는 1가지 폴더(__public__)로 지정해 주세요.
  ```
    /apps
      ├ Host
      ├ App 1
      │  ├ public *
      │  ├ src
      │  │  ├ index.tsx
      │  │  └ vite-env.d.ts
      │  └ vite.config.ts
      └ App 2
         ├ public *
         ├ src
         │  ├ index.tsx
         │  └ vite-env.d.ts
         └ vite.config.ts
  ```
  * <span style="color:#f39">__public 폴더가 아닐 시__</span> 아래 내용에 public은 다른 값으로 수정해야 합니다.

  <br />

  2. 지정된 폴더는 번들링 툴(Vite)의 __define__ 기능을 사용
  ```js
    ...
    import path from 'path'
    import envs from '../../packages/env/env-common';

    export default defineConfig((({ mode }: any) => {
      const remote = (envs.remoteAppHost as any)[mode];

      return {
        publicDir: path.resolve(__dirname, './public'),
        define: { '$resourceUrl': JSON.stringify(remote.app1) },
        ...
      };
    }))

  ```
  * vite.config.ts 기준

    |이름|설명|
    |----|----|
    |publicDir|개발/배포 시 공개 가능한 기본경로 (URL)|
    |define|번들링을 통한 상수 설정 (앱, 개발/배포에 따른 주소가 적용될 곳)|
    |../../packages/env/env-common|통합을 위한 환경 변수 모음 → [관련문서 이동](./5.%20add-app%20guide.md)|

  <br />

  3. App에서 Typescript를 사용하고 있을 경우
  ```ts
    declare const $resourceUrl: string;
  ```
  * vite-env.d.ts 혹은 global.d.ts 파일 내에 전역변수 등록해야 빌드 시 문제가 없습니다.

  <br />

  4. 이미지 불러오기 샘플 코드
  ```ts
    // [Type 1 - O]
    export default function(){
      return <img src={`${$resourceUrl}/logo.png`} />;
    }
  ```
  ```ts
    // [Type 2 - O]
    export default function(){
      const imgUrl = `${$resourceUrl}/logo.png`;
      return <img src={imgUrl} />;
    }
  ```
  ```ts
    // [Type 3 - X]
    import imgUrl from 'logo.png';
    export default function(){
      return <img src={imgUrl} />;
    }
  ```
  * 리소스와 관련된 코드는 위 샘플과 같이 사용하여야 하고,<br />
    Type 3과 같이 <span style="color:#fd3">__직접 import__</span>를 할 경우 <span style="color:#f39">__통합 빌드 시 문제__</span>가 됩니다.
