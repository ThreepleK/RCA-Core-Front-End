# Module federation의 shared 설정  
  ```ts
    export default defineConfig((({ mode }: any) => {
        ...
        return {
            ...
            plugins: [
                federation({
                    ...
                    shared: {
                        react: { singleton: true },
                        '@repo/shared-state': { singleton: true }
                    }
                }),
            ],
            ...
        };
    }))
  ```
  apps/* 내에 <span style='color:#fd3'>__vite.config.ts__</span>를 보면<br />
  shared 옵션을 지정하여 설치된 패키지의 Host와 App간의 규칙을 정할 수 있습니다.


  |옵션|유형|기본 값|
  |----|----|----|
  |singleton        |boolean            |false|
  |requiredVersion  |string             |require('project/package.json')[devDeps \| dep]['depName']|
  |eager            |boolean            |false|
  |shareScope       |string             |'default'|
  |import           |string \| false    |undefined|

  표와 같이 여러 옵션이 있지만 중요한 것은 __singleton__ 입니다. <br /><br />

  위 예시는 @repo/shared-state(/packages/shared-state)를 공유함으로 <br />
  Host와 연결된 설정된 __모든 앱간의__ <span style='color:#f3d'>__동일한 상태 공유를 할 수 있습니다.__</span><br /><br />

  추가 설명과 다른 옵션에 대해 알고 싶다면 → [바로가기](https://module-federation.io/configure/shared.html)
