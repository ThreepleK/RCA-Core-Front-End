# Style은 3가지 방법 중 필요한 형태로

  |방법|설명|
  |----|----|
  |CSS Module|권장|
  |CSS-in-JS|비 권장 (특수상황 시)|
  |Tailwindcss|권장|

<br />

# 그냥 css를 호출하여 사용하면 안되는 이유

  ```
  Project
    └ Host     http://localhost:5000
      ├ App 1  http://localhost:5001
      ├ App 2  http://localhost:5002
      └ ...
  ```
  각각의 앱은 실제 개발/배포 시에 <span style="color:#f39">__한 화면__</span>을 사용하게 됩니다.<br />
  이 때 <span style="color:#fd3">__style__</span>이
  <span style="color:#39f">__Overriding(상속)__</span>됨으로 원치 않는 결과로 이어질 수 있습니다.

  ```css
  /* Host - index.css */
  button { background: yellow; width: 100px; height: 30px; }
  ```
  ```css
  /* App 1 - index.css */
  button { background: blue; font-size: 12px; }
  ```
  ```css
  /* App 2 - index.css */
  button { background: black; border-radius: 10px; border: 1px solid #ccc; }
  ```
  위 예시와 같다면 각 App 1, 2는 원치 않는 <span style="color:#fd3">__넓이와, 높이__</span>를 <span style="color:#39f">__상속__</span>받게 되며,<br />
  App 1 → App 2를 이동하게 되면, App 2의 버튼은 원치 않는 <span style="color:#fd3">__폰트 크기__</span>를 <span style="color:#39f">__상속__</span> 받게 됩니다.

<br />

# 1. CSS Module
  각 <span style='color:#39f'>__컴포넌트 단위__</span>로 중첩되지 않은 style을 사용하는데 좋은 방법 입니다.<br />
  아래는 단순한 코드 예시 입니다.
  ```
  src
    ├ button.module.css
    └ button.tsx
  ```
  ```css
    /* button.module.css */
    .button {
      display: flex;
      align-items: center;
      justify-content: center;
      width: 100px;
      height: 30px;
      border: 1px solid #ccc;
    }
  ```
  ```tsx
    // button.tsx
    import style from './button.module.css'

    export default function(){
      return <button className={style.button}>Click Me!</button>
    }
  ```

# 2. CSS-in-JS
  특수한 경우가 아니라면 권장하지 않습니다.<br />
  사용을 원한다면 아래 3.Tailwindcss를 사용해주세요.

# 3. Tailwindcss
  미리 정해진 규칙을 사용하며,<br />
  App 간의 스타일을 해치지 않고 스타일을 정의 할 수 있다는 점<br />
  또한 통일된 스타일을 유지하는데 도움을 받을 수 있습니다.

  ```tsx
    // button.tsx
    export default function(){
      return <button className={`flex items-center justify-center w-[100px] h-[30px] border-1 border-[#ccc] border-solid`}>Click Me!</button>
    }
  ```
  
  1. test에 설치
  ```sh
    > cd apps/test
    > pnpm add -D postcss postcss-preset-mantine postcss-simple-vars @tailwindcss/postcss
    > pnpm add -D autoprefixer
    > pnpm add -D tailwindcss @tailwindcss/vite
    > pnpm add -D tailwind-merge clsx
  ```
  * apps/test는 [add-app guide](./5.%20add-app%20guide.md)에서 이미 앱이 만들어진 상태일 경우
  
  <br />

  2. vite.config.ts 설정 값 추가
  ```ts
    import tailwindcss from '@tailwindcss/vite'

    export default defineConfig((({ mode }: any) => {
      ...
      return {
        plugins: [
          ...
          tailwindcss(),
        ],
      };
    }))
  ```
  * plugins에 tailwindcss 추가

  <br />

  3. index.css
  ```css 
    @import "tailwindcss";
  ```
  * 앱에서 가장 루트에 사용되는 css 파일이 index.css일 경우 위 코드 값 추가
