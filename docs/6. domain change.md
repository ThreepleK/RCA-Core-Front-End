## [배포 Type A] Module federation 원격 주소 변경 방법 (같은 도메인)
  1. /packages/env/env-common.ts
  ```ts
    // 운영에서 사용 될 원격 기본 주소
    const _PROD_HOST_REMOTE = `${_PROD_HOST}/r`;
  ```
  * 환경변수는 위의 값을 변경 하면 되고

  2. /prod-build.sh
  ```sh
    if [ "$name" = "host" ]; then
        ...
    else
        mkdir -p "./dist/r/$name"
        cp -r "$dir/"* "./dist/r/$name/"
    fi
  ```
  * 빌드 시 환경변수에서 수정한 위치와 경로를 맞춰주면 됩니다.

  <br /><br />

## [배포 Type B] Module federation 원격 주소 변경 방법 (각각의 컨테이너, 포트)
  1. /docker-compose/remote/docker-compose.yml
  ```yml
    tt:
        build:
            context: .
            dockerfile: ./dockerfile-remote
            args:
                DIST_PATH: ./dist/r/tt
            container_name: tt
            ports:
                - "5001:80"
  ```
  * services 하위에 아래와 같은 구성의 포트(5001)를 변경

  <br />

  2. /docker-compose/remote/nginx.conf
  ```
    http {
        ...
        upstream tt {
            server tt:80;
        }

        server {
            ...
            # tt 프록시
            location /r/tt/ {
                ...
                proxy_pass http://tt/;
                ...
            }
            ...
        }
    }
  ```
  * location (/r/tt/) 주소가 Host에서 tt로 접근 할 주소

  <br />

  3. /packages/env/env-common.ts
  ```ts
    //* 원격 앱 개발/배포 주소
    remoteAppHost: {
        ...
        production: {
            ...
            tt: `${_PROD_HOST_REMOTE}/tt`,
        },
    },
  ```

  * 앱의 전체 구성을 다 바꾼다면 **_PROD_HOST_REMOTE** 변수의 값을 바꾸고
  * tt를 바꾸고자 한다면 아래와 같이 변경하여 2에서 수정한 것과 같이 변경하면 됩니다.

  ```ts [/packages/env/env-common.ts]
    //* 원격 앱 개발/배포 주소
    remoteAppHost: {
        ...
        production: {
            ...
            tt: `${_PROD_HOST}/r/tt`,
        },
    },
  ```
